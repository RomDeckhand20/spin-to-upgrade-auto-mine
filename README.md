# Spin To Upgrade Idle Engine

Idle engine for Spin To Upgrade: resource extraction and inventory turnover run as one continuous loop.

## Scope

The toolkit bundles 4 modules: automated resource extraction, automated inventory turnover, hands-free progression loop, Upgrade Items. All are optional toggles in the in-game menu.

1. Join the game.
2. Attach your runtime and execute the line above.
3. The menu builds in-game; enable modules one at a time.
